The build is published to npm as `@openproject/commonmark-ckeditor-build`. It is no longer written into `frontend/src/vendor/ckeditor/` of an OpenProject checkout. Import the package for the bundle, `@openproject/commonmark-ckeditor-build/ckeditor.css` for the stylesheet, and `loadTranslation` from `@openproject/commonmark-ckeditor-build/translations` for a locale.
